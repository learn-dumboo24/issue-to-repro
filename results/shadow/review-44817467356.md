## Why nothing was shared

- The Click and Jinja issues show many deleted drive-by comments and blocked accounts;
  click#3914 is locked to collaborators as a spam target. An unsolicited generated test would be
  unwelcome there.
- attrs#1596 has an open pull request; attrs#1637 has a reference to one.

## What this shows

Backtests looked precise because the real fix acts as a final check: a test that asserts the
wrong thing fails it. On open issues there is no fix yet, and the sandbox alone accepted tests
with wrong or extra assertions.

## Changes made because of this review

1. **Sandbox:** a test file in which some tests fail and others pass is now `invalid`, not
   `reproduced`, with a note telling the agents why (would have rejected jinja#2269 as written).
2. **Instructions:** keep the reporter's module-level code at module level (attrs#1596); assert
   only behaviour the issue states as expected and never the current buggy behaviour or something
   the reporter says is correct (jinja#2269, click#3915); no debug prints (click#3914); the
   classifier labels "is this intended?" reports as `question` (attrs#1637).

The next shadow run measures whether these changes help.
