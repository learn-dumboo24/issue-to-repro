## What this shows

A new failure mode: when the reported behaviour cannot be reproduced, the agents kept trying until
something failed, and the sandbox accepted it because the test did fail. The verdict is right about
the test and wrong about the bug.

## Changes made because of this review

1. **Instructions:** if a bug needs something the sandbox cannot provide (another operating
   system, hardware, a network or a service) or happens only some of the time, the reproducer
   writes no test and says why. Code that only handles another platform's data, such as Windows
   paths in click#3915, can still be tested.
2. **Instructions:** test the reported behaviour through the public API, never how the code is
   written (mocked internal calls); the verifier rejects such tests.
3. **Targets:** Flask and more-itertools added, since few new issues passed the selection rules.
