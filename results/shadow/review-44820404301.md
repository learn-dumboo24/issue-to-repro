## What this shows

- The two failures the changes targeted are fixed: no test asserts the buggy behaviour
  (jinja#2269) and module-level code stays at module level (attrs#1596).
- The two remaining failures come from the model not following an instruction it was given:
  "never change behaviour the reporter says is correct" (click#3915) and "a report asking whether
  the behaviour is intended is a question" (attrs#1637).
- 5 issues and one run each: model output varies between runs, so this is an encouraging signal,
  not a measured improvement. More runs on new issues will tell.
